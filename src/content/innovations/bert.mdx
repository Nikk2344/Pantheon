## A representation changes with the sentence

A fixed dictionary vector gives a word the same representation whenever it appears. A contextual encoder can represent a token differently depending on the surrounding sentence. BERT learns such representations by predicting selected tokens using the remaining context.

The original system also used a next-sentence prediction objective. It should not be described as simply reading every word and freely generating an answer like a chat assistant.

## A concrete comparison

Compare “They sat on the bank beside the river” with “They contacted the bank about a loan.” The shared word is not enough to settle the meaning. A representation useful for a question-answering system needs the surrounding evidence. This is an explanatory example, not a benchmark result.

For extractive question answering, a model can learn to select the beginning and end of an answer span in a supplied passage. That task differs from composing an unrestricted response, and a good result on it does not establish that the model will avoid inventing unsupported claims elsewhere.

## The recipe needs scrutiny

RoBERTa later examined choices including training duration, data, masking, and removal of the next-sentence objective. Its findings caution against attributing every gain to a distinctive architectural name. Experimental comparisons should account for the training budget and data as well as the model diagram.

## Follow the evidence

Ask whether evaluation examples overlap with training material, whether the task resembles the intended application, and whether performance differs across language varieties. A single average can conceal important weaknesses. The contrast with [InstructGPT](/innovations/instructgpt) is useful: representation pretraining and instruction-following optimisation solve related but different problems.
